# FotNep - Nepali Football Analytics Platform

Advanced analytics and prediction platform for Nepali football using machine learning algorithms.

## Project Overview

FotNep provides intelligent match analysis, player performance prediction, and squad optimization through three core ML algorithms:

1. **Crowd Consensus Prediction** - Community-driven match outcome forecasting with reputation weighting
2. **Player Performance Estimator** - Compare players with ML-predicted stats from available data
3. **Optimal Squad Generator** - Predict ideal match lineups based on historical performance and player availability

## Tech Stack

- **Frontend:** React 18 + TypeScript + Tailwind CSS
- **Backend:** Express.js + MongoDB
- **ML Service:** FastAPI + Python (scikit-learn)
- **Data:** 102 Nepali players + European comparison dataset
